# CubeChat

CubeChat is an open-source, privacy-first anonymous chat application. Designed for simplicity and security, CubeChat allows users to communicate in real-time without the need for registration or personal information. All messages are ephemeral and **no chat data is stored**—ensuring complete privacy and anonymity for all participants.

## Features

- **Anonymous Chat:** No accounts, no signups, no user tracking—just join and start chatting.
- **End-to-end Privacy:** Messages are never stored on the server. Once delivered or the chat ends, your conversation disappears forever.
- **Real-Time Communication:** Enjoy seamless, instant messaging with others in the chat room.
- **No Data Retention:** CubeChat does **not** log, archive, or save messages or user data.
- **Minimal UI:** Lightweight and intuitive design, built with JavaScript, CSS, and HTML.

## How It Works

CubeChat leverages modern web technologies to provide secure, real-time chat functionality:
- **Frontend:** JavaScript, CSS, and HTML for a fast, responsive interface.
- **Privacy Focus:** All chat data exists only in memory during the session and is never written to disk or a database.

## Getting Started

1. **Clone the repository:**
    ```sh
    git clone https://github.com/NoE114/cubechat.git
    cd cubechat
    ```

2. **Open `index.html` in your browser**, or deploy the app on your favorite static site host.

3. **Start chatting anonymously!**

## Why CubeChat?

Unlike typical chat applications, CubeChat puts user privacy first. Whether you're having a sensitive conversation or just want to chat freely, you can trust that your data is never recorded or sold.
